# Jarvis — голосовой ассистент для Android

Скелет полноценного Android-приложения (Kotlin) с голосовым управлением
телефоном. Ниже — как собрать, что уже работает, и как довести до нужного вам уровня.

## Что уже реализовано

| Команда (пример фразы) | Что делает |
|---|---|
| "громкость больше / меньше / 50" | AudioManager, меняет громкость медиа |
| "яркость больше / меньше / 30" | Settings.System, меняет яркость экрана |
| "пауза" / "продолжи" | MediaSession play/pause в ЛЮБОМ плеере (YouTube, Spotify, кино-приложения) |
| "перемотай вперёд / назад" | seekTo() на 15 сек через MediaSession |
| "начни сначала" | seekTo(0) |
| "домой" / "назад" | AccessibilityService global actions |
| "заблокируй экран" | AccessibilityService lock screen |
| "включи wifi" / "энергосбережение" | открывает соответствующую системную панель одним касанием |
| "открой Youtube / зайди в Spotify" | ищет установленное приложение по названию и запускает |
| всё остальное | уходит как вопрос в AiFallbackHelper (заглушка под LLM-ответ) |

## Сборка

1. Установите **Android Studio** (последняя стабильная версия).
2. Откройте папку `JarvisAssistant` как проект (`Open` → выбрать эту папку).
3. Дайте Gradle синхронизироваться (он подтянет зависимости автоматически).
4. Подключите телефон по USB с включённой отладкой по USB, нажмите Run.

## Обязательная настройка на телефоне после установки

Приложение **не может** включить эти права само — так устроен Android
(иначе любое приложение могло бы шпионить). При первом запуске нажмите
по порядку кнопки 1–4 на главном экране приложения:

1. Разрешить микрофон — стандартный диалог Android.
2. Разрешить менять яркость — откроется системная страница, включите тумблер.
3. Включить Accessibility Service — откроется список служб специальных
   возможностей, найдите "Jarvis" и включите. **Без этого не будут
   работать команды "домой/назад/заблокируй экран".**
4. Разрешить доступ к медиасессиям — то же самое для управления плеерами
   play/pause/перемотка.

После этого жмите "Запустить Джарвиса" — появится уведомление о фоновой
работе (Android требует его показывать, пока используется микрофон).

## Честно про ограничения (важно прочитать)

- **Выключить телефон командой голосом — невозможно** для обычного
  приложения без root-прав или статуса системного приложения. Google
  специально это запретил из соображений безопасности. Максимум — блокировка
  экрана, которая доступна.
- **Wi-Fi и энергосбережение** нельзя включить/выключить одной командой
  без единого касания — с Android 10 сторонним приложениям это тоже
  запрещено. Ассистент открывает нужный экран настроек, и вам останется
  один тап. Это не наша недоработка, а системное ограничение ОС.
- **Голос "как в фильме"** — это голос актёра Пола Беттани, клонировать
  его нельзя (авторские права + генерация голоса реального человека без
  согласия — плохая идея и с этической, и с юридической стороны). В
  проекте настроен спокойный, слегка низкий голос через стандартный
  Android TTS. Если хочется куда более качественный и киношный (но
  НЕ идентичный оригиналу) голос — см. ниже.

## Улучшение точности микрофона

Если стандартный `SpeechRecognizer` продолжает "мазать" (частая жалоба —
он использует облачное распознавание Google и плохо держит удар на шуме
или слабом интернете), замените его на офлайн-движок **Vosk**:

1. Добавьте зависимость `implementation 'com.alphacephei:vosk-android:0.3.47'`
2. Скачайте небольшую русскую модель (vosk-model-small-ru) — работает
   полностью локально, без интернета, и на моём опыте заметно точнее
   ловит короткие командные фразы, чем облачный движок.
3. Замените `SpeechRecognizer` в `VoiceRecognitionService` на `Recognizer`
   из Vosk — принцип тот же (слушать → callback с текстом → в
   `CommandProcessor`), просто источник другой.

Это не переписывание архитектуры — меняется только один класс.

## Более качественный (но не "тот самый") голос

Стандартный TTS звучит по-android-овски. Для более киношного тембра:
1. Зарегистрируйтесь в сервисе нейро-TTS (например ElevenLabs) и создайте
   голос через готовые "дикторские" пресеты (не клонирование реального человека).
2. В `TtsHelper` вместо `android.speech.tts.TextToSpeech` делайте HTTP-запрос
   к API сервиса, получаете аудио-файл, проигрываете через `MediaPlayer`.
3. Это платно (по объёму символов), но качество голоса на порядок выше.

## Новое: сон / пробуждение по слову

По умолчанию сервис стартует в режиме "сплю". Скажите **"Джарвис"** —
проснётся и либо выполнит команду, сказанную в той же фразе ("Джарвис,
включи фонарик"), либо просто ответит "Да, сэр" и будет ждать следующую
фразу. Скажите **"спи"** — снова уйдёт в ожидание и не будет реагировать
ни на что, кроме имени. Работает и при выключенном экране (добавлен
partial wake lock, чтобы CPU не засыпал).

## Новое: память, макросы, фонарик, фильмы, реклама

- **"Запомни, что мой рейс завтра в 9"** → "что ты помнишь про рейс" вернёт эту фразу.
- **"Запомни команду <имя>"** → сделайте вручную нужный тап в приложении →
  скажите "сохрани" — Джарвис свяжет имя команды с этим элементом экрана.
  Дальше просто произносите это имя, и он повторит клик. Работает по
  тексту элемента — если приложение поменяет разметку, макрос слетит.
- **"Включи/выключи фонарик"** — CameraManager.setTorchMode, работает сразу.
- **"Фильм Матрица"** — открывает браузер с поиском "смотреть онлайн
  русская озвучка". Автоматический вход на конкретный сайт и клик по
  плей/fullscreen я сознательно не жёстко прошил под один сайт (типа
  HDrezka), потому что верстка сайтов меняется и хрупкий скрипт под
  конкретный домен сломается через месяц. Общая команда "полноэкранный
  режим" после того, как сайт открыт, — пробует найти и нажать кнопку
  fullscreen на странице.
- **"Пропусти рекламу"** — best-effort клик по кнопкам вида "×",
  "Закрыть", "Skip Ad". Реклама намеренно верстается так, чтобы это было
  сложно автоматизировать, так что 100% результата не обещаю.

## Честно: что из вашего списка НЕ реализовано и почему

| Хотелось | Почему не делаю |
|---|---|
| Тихая установка/удаление приложений без вашего тапа | Требует root/статус системного приложения — Android запрещает |
| Toggle Wi-Fi/Bluetooth без тапа | Запрещено сторонним приложениям с Android 10/13 |
| Голос 1-в-1 как у актёра из фильма | Клонирование голоса живого человека без согласия — юридически и этически недопустимо |
| Нулевая задержка распознавания | Физический предел сети/движка — минимум с офлайн-Vosk, но не 0 |
| Автоматизация Instagram/Telegram (сравнение подписчиков, авто-действия) | Это бот против чужого сервиса — риск блокировки вашего аккаунта, и это скрапинг данных других людей. Не буду встраивать |
| "Исправлять ошибки/код на телефоне" | Обычное приложение не имеет доступа к логам чужих приложений — уточните, что именно имелось в виду |
| Полное "умный как в фильме" понимание любых формулировок | Возможно только через постоянный вызов LLM на каждую фразу — заложено через AiFallbackHelper, но нужен ваш backend с ключом |

## Как добавить новые команды

Всё сосредоточено в `CommandProcessor.kt` — один `when` с regex-условиями.
Добавить новую команду — значит добавить один `case`, который парсит
нужную фразу и вызывает метод в `SystemController` / `MediaControlHelper`
(или новый метод, если функциональности пока нет).

## Про свободные вопросы ("Джарвис, какая погода?")

`AiFallbackHelper.kt` — заглушка. Чтобы Джарвис реально отвечал на
произвольные вопросы, поднимите небольшой backend-прокси (пару строк
на Cloudflare Worker/Node.js), который:
- принимает вопрос от приложения,
- обращается к Anthropic API со своим серверным ключом (**ключ никогда
  не должен лежать внутри APK** — его легко достать декомпиляцией),
- возвращает текстовый ответ.

Подставьте адрес своего прокси в `PROXY_URL` внутри `AiFallbackHelper.kt`.
